# The Rust Programming Language

## Installation

Pehla step hai Rust ko install karna. Hum Rust ko `rustup` ke through download karenge, jo ki ek command line tool hai Rust versions aur usse jude tools ko manage karne ke liye. Download ke liye aapko ek internet connection ki zaroorat padegi.

> **Note:** Agar aap kisi wajah se `rustup` use nahi karna chahte, toh aur options ke liye please [Other Rust Installation Methods](https://forge.rust-lang.org/infra/other-installation-methods.html) page dekhein.

Neeche diye gaye steps Rust compiler ka latest stable version install karte hain. Rust ki stability guarantees yeh sunishchit (ensure) karti hain ki is book ke saare examples jo compile hote hain, woh naye Rust versions ke saath bhi compile hote rahenge.

Output versions ke beech thoda alag ho sakta hai kyunki Rust aksar error messages aur warnings ko improve karta rehta hai.

Dusre shabdon mein, in steps ka use karke aap jo bhi naya, stable Rust version install karenge, woh is book ke content ke saath umeed ke mutabik (as expected) kaam karega.

### Command Line Notation

Is chapter aur poori book mein, hum terminal mein use hone waali kuch commands dikhayenge.

- Jo lines aapko terminal mein enter karni hain, woh sab `$` se shuru hoti hain.
- Aapko `$` character type karne ki zaroorat nahi hai; yeh sirf command line prompt hai jo har command ki shuruat dikhane ke liye use hota hai.
- Jo lines `$` se shuru nahi hoti hain, woh aam taur par pichli command ka output dikhati hain.
- Iske alawa, PowerShell-specific examples mein `$` ki jagah `>` ka use hoga.

### Installing rustup on Linux or macOS

Agar aap Linux ya macOS use kar rahe hain, toh ek terminal kholein aur neeche di gayi command enter karein:

**Bash**

```bash
$ curl --proto '=https' --tlsv1.2 https://sh.rustup.rs -sSf | sh
```

Yeh command ek script download karti hai aur `rustup` tool ka installation shuru karti hai, jo Rust ka latest stable version install karta hai.

Aapse aapka password maanga ja sakta hai. Agar install successful hota hai, toh neeche di gayi line dikhai degi:

**Plaintext**

```text
Rust is installed now. Great!
```

Aapko ek linker ki bhi zaroorat padegi, jo ki ek aisa program hai jise Rust apne compiled outputs ko ek file mein jodne ke liye use karta hai.

Is baat ki poori sambhavna hai ki aapke paas yeh pehle se ho. Agar aapko linker errors aate hain, toh aapko ek C compiler install karna chahiye, jisme aam taur par ek linker shaamil hota hai.

Ek C compiler isliye bhi kaam ka hota hai kyunki kuch common Rust packages C code par depend karte hain aur unhe ek C compiler ki zaroorat padegi.

**macOS par**, aap yeh command run karke C compiler pa sakte hain:

**Bash**

```bash
$ xcode-select --install
```

**Linux users** ko aam taur par apni distribution ki documentation ke hisaab se GCC ya Clang install karna chahiye.

Example ke liye, agar aap Ubuntu use karte hain, toh aap `build-essential` package install kar sakte hain.

### Installing rustup on Windows

Windows par, [Rust Installation](https://www.rust-lang.org/tools/install) page par jayein aur Rust install karne ke instructions follow karein.

Installation ke kisi point par, aapse Visual Studio install karne ke liye kaha jayega. Yeh ek linker aur woh native libraries provide karta hai jo programs ko compile karne ke liye zaroori hoti hain.

Agar aapko is step mein aur madad chahiye, toh [Windows MSVC Installation Guide](https://rust-lang.github.io/rustup/installation/windows-msvc.html) dekhein.

Is book ka baaki hissa aisi commands use karta hai jo `cmd.exe` aur PowerShell dono mein kaam karti hain.

Agar kahin koi khaas fark hoga, toh hum batayenge ki kaun sa use karna hai.

## Troubleshooting

Yeh check karne ke liye ki aapne Rust sahi tareeke se install kiya hai ya nahi, ek shell kholein aur yeh line enter karein:

**Bash**

```bash
$ rustc --version
```

Aapko release kiye gaye latest stable version ka version number, commit hash, aur commit date is format mein dikhai dena chahiye:

**Plaintext**

```text
rustc x.y.z (abcabcabc yyyy-mm-dd)
```

Agar aapko yeh jaankari dikhti hai, toh aapne Rust successfully install kar liya hai!

Agar aapko yeh jaankari nahi dikhti hai, toh neeche diye gaye tareeke se check karein ki Rust aapke `%PATH%` system variable mein hai ya nahi.

**Windows CMD mein**, use karein:

**DOS**

```dos
> echo %PATH%
```

**PowerShell mein**, use karein:

**PowerShell**

```powershell
> echo $env:Path
```

**Linux aur macOS mein**, use karein:

**Bash**

```bash
$ echo $PATH
```

Agar yeh sab sahi hai aur Rust phir bhi kaam nahi kar raha hai, toh aisi kai jagah hain jahan se aap madad le sakte hain.

[Community Page](https://www.rust-lang.org/community) par jaakar pata karein ki doosre Rustaceans (ek ajeeb/silly nickname jo hum khud ko dete hain) se kaise sampark (contact) kiya jaye.

## Updating and Uninstalling

Ek baar jab Rust `rustup` ke zariye install ho jata hai, toh naye release hue version par update karna aasaan hai.

Apne shell se, neeche di gayi update script run karein:

**Bash**

```bash
$ rustup update
```

Rust aur `rustup` ko uninstall karne ke liye, apne shell se neeche di gayi uninstall script run karein:

**Bash**

```bash
$ rustup self uninstall
```

## Reading the Local Documentation

Rust ke installation mein documentation ki ek local copy bhi shaamil hoti hai taaki aap ise offline padh sakein.

Apne browser mein local documentation kholne ke liye `rustup doc` run karein.

```bash
$ rustup doc
```

Jab bhi koi type ya function standard library dwara provide kiya gaya ho aur aapko pakka pata na ho ki woh kya karta hai ya use kaise use karna hai, toh pata lagane ke liye application programming interface (API) documentation ka use karein!

## Using Text Editors and IDEs

Yeh book is baat par koi assumption nahi banati ki aap Rust code likhne ke liye kaun se tools use karte hain.

Lagbhag koi bhi text editor kaam kar dega!

Haalanki, kai text editors aur integrated development environments (IDEs) mein Rust ke liye built-in support hota hai.

Aap Rust website par [Tools Page](https://www.rust-lang.org/tools) the tools page par hamesha kai editors aur IDEs ki ek kaafi updated (fairly current) list pa sakte hain.

## Working Offline with This Book

Kai examples mein, hum standard library ke alawa bhi Rust packages ka use karenge.

Un examples par kaam karne ke liye, aapke paas ya toh internet connection hona chahiye ya aapko woh dependencies pehle se download karke rakhni hongi.

Dependencies ko pehle se download karne ke liye, aap neeche di gayi commands run kar sakte hain.

> **Note:** Hum baad mein detail mein samjhayenge ki Cargo kya hai aur inmein se har ek command kya karti hai.

**Bash**

```bash
$ cargo new get-dependencies
$ cd get-dependencies
$ cargo add rand@0.10.1 trpl@0.2.0
```

Yeh in packages ke downloads ko cache kar dega taaki aapko baad mein inhe download karne ki zaroorat na pade.

Ek baar jab aap yeh command run kar lete hain, toh aapko `get-dependencies` folder rakhne ki zaroorat nahi hai.

Agar aapne yeh command run kar li hai, toh aap network ka use karne ke bajaye in cached versions ko use karne ke liye book ke baaki hisse mein sabhi Cargo commands ke saath `--offline` flag ka use kar sakte hain.
