# The Rust Programming Language

## Common Programming Concepts

Yeh chapter un concepts ko cover karta hai jo lagbhag har programming language mein aate hain aur yeh dekhte hain ki ye Rust mein kaise kaam karte hain. Bahut saari programming languages ke core mein kaafi cheezein common hoti hain. Is chapter mein jitne bhi concepts pesh kiye gaye hain, unmein se koi bhi Rust ke liye unique nahi hai, lekin hum inhein Rust ke context mein discuss karenge aur inke use ke around jo conventions hain unhein explain karenge.

Specifically, aap niche diye gaye topics ke baare mein seekhenge:

- **Variables**
- **Basic types**
- **Functions**
- **Comments**
- **Control flow**

Yeh foundations har Rust program mein hongi, aur inhein shuruat mein seekh lene se aapko start karne ke liye ek strong core mil jayega.

### Keywords

Rust language mein **keywords** ka ek set hota hai jo sirf language ke use ke liye reserved hote hain, bilkul doosri languages ki tarah. Yeh dhyaan rakhein ki aap in words ko variables ya functions ke naam ke taur par use nahi kar sakte.

- Zyadatar keywords ke special meanings hote hain, aur aap inka use apne Rust programs mein alag-alag tasks karne ke liye karenge.
- Kuch keywords ke paas abhi koi current functionality associated nahi hai, lekin unhein aisi functionality ke liye reserve kiya gaya hai jo shayad future mein Rust mein add ki jaye.

> **Tip:** Aap Rust ke sabhi keywords ki complete list **Appendix A** mein pa sakte hain.
